# Бритва — сайт барбершопа с 3D и онлайн-записью

Демо-проект для портфолио: барбершоп вымышленный, сайт рабочий.

**Открыть:** https://davnat0111-gif.github.io/britva-barbershop/

## Что умеет
- **3D-сцена на Three.js:** столб барбера под стеклом с бегущими полосами и опасная бритва, которая раскрывается при прокрутке. Сцена следит за курсором, в воздухе летает золотая пыль, металл даёт свечение (bloom).
- **Онлайн-запись за 4 шага:** услуга → мастер → дата и время → контакты. Занятое и прошедшее время выбрать нельзя, итог считается сразу, телефон форматируется маской +7 (___) ___-__-__.
- **Современная вёрстка:** карточки с 3D-наклоном и подсветкой под курсором, появление блоков при прокрутке, бегущая строка, адаптив под телефон.
- Плашка «открыто / закрыто» по реальному времени.

## Как сделано
- HTML, CSS и JavaScript без фреймворков, Three.js r160 лежит в репозитории
- Окружение для отражений строится в коде (PMREM из сцены с софтбоксами), поэтому внешние HDR-файлы не нужны
- Рендер ставится на паузу, когда главный экран не виден, чтобы не тратить батарею
